ViviMess — Game invites

В чате ссылка вида https://www.roblox.com/games/123456 автоматически получает синюю кнопку «Играть».
В Creator Studio: вкладка -> добавить Button -> Action: Launch game -> вставить URL -> Save.
Кнопка открывает ссылку Roblox. Запуск установленного клиента зависит от Roblox и браузера; сайт не может гарантировать автоматический запуск игры без подтверждения.
Для обновления загрузите содержимое vm-work в корень GitHub.
