ViviMess 5.7 — полный редизайн звонков

- Новое окно звонка в тёмной палитре ViviMess с бирюзовыми и синими акцентами.
- Большая центральная сцена для демонстрации экрана.
- Для голосового звонка — крупная карточка собеседника с анимацией.
- Статусы соединения перенесены из центра сцены в отдельную строку, поэтому надпись Voice connected больше не закрывает демонстрацию.
- Нижняя панель управления: микрофон, показ экрана, полноэкранный режим, завершение звонка.
- Полноэкранный режим скрывает шапку и нижнюю панель, оставляя демонстрацию на весь экран.
- Адаптация для мобильных экранов.

Обновление интерфейса не требует изменения data.json. Не загружайте пустой data.json поверх существующей базы.
Проверка: JavaScript syntax check; браузерное тестирование звонков и WebRTC на двух устройствах не выполнялось. Для стабильных соединений между разными сетями может понадобиться TURN.
