ViviMess 5.6 — обновление интерфейса и управления

Что изменено:
- Увеличена область переписки; декоративная верхняя панель скрыта.
- Обложки Roblox отображаются целиком без обрезания.
- Добавлен отдельный файл public/custom.css; пользовательский CSS из Creator Studio сохраняется в data.json и применяется после базовых стилей.
- В Creator Studio добавлена настройка видимости встроенных и пользовательских вкладок слева.
- Настройки видимости сохраняются на сервере и применяются всем пользователям.
- Сохранение data.json теперь атомарное; предыдущая версия сохраняется в data.json.bak. При повреждённом JSON сервер прекращает запуск вместо создания пустой базы.
- Путь к базе можно задать переменной окружения DATA_DIR (например /var/data на постоянном диске Render).

ВАЖНО О СОХРАННОСТИ ДАННЫХ:
- В этот ZIP не входит data.json. Не загружайте поверх него пустой data.json и не удаляйте существующую базу.
- Для сохранения аккаунтов и переписок между деплоями Render должен быть подключён Persistent Disk, смонтированный, например, в /var/data, а переменная DATA_DIR должна иметь значение /var/data.
- Если Render использует временную файловую систему без Persistent Disk, никакой код приложения не может гарантировать сохранность data.json после замены экземпляра. Перед деплоем сделайте копию существующего data.json.

Управление вкладками:
- Creator Studio → Видимость вкладок → снимите галочки с вкладок, которые нужно скрыть, затем нажмите «Сохранить видимость».
- Если скрыли саму Creator Studio, владелец может открыть её сочетанием Alt+Shift+V.
