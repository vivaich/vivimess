ViviMess — обновление валют и кнопок Creator Studio

Что добавлено:
1. В Creator Studio у каждой валюты появилась кнопка Delete. Удаление стирает эту валюту и её балансы у всех пользователей. Это действие необратимо.
2. В разделе управления балансом можно явно выбрать Give currency или Take currency. Сумма вводится положительным числом; при списании баланс не опустится ниже нуля.
3. Для кнопок на пользовательских вкладках добавлен режим Run my JavaScript code.

Доступные функции в коде кнопки:
vm.toast("Текст сообщения");
vm.navigate("slug-вкладки");
vm.giveCurrency("ID_ВАЛЮТЫ", 10);

Код запускается в изолированном iframe без доступа к токенам, паролям, хранилищу сайта и сетевым запросам. Для выдачи валюты укажите существующий ID валюты и положительное количество. ID валюты можно посмотреть в настройке кнопки Give currency или в данных валюты.

Установка:
Замените файлы проекта на GitHub содержимым папки vm-work, сделайте Commit changes и дождитесь Render: Live. Не удаляйте data.json и не очищайте Render Disk.
