ViviMess 5.4 — Roblox game cards

- Исправлено получение метаданных игры по публичным Roblox API без .ROBLOSECURITY.
- Place ID преобразуется в Universe ID.
- Загружаются название игры, имя создателя и обложка; есть запасной вариант с иконкой игры.
- В карточке отображается число игроков, если Roblox его возвращает.
- Ошибки API больше не маскируются под успешные данные.

Примечание: доступность публичных Roblox API и обложек зависит от Roblox.
