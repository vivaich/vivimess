ViviMess 2.0 — пакет обновления

Включено в эту сборку:
- текущая функциональность чатов, заявок в друзья, медиа-вложений, GIF-коллекции и пользовательских страниц;
- роли administrator / moderator / user;
- модераторский просмотр профиля пользователя, списка друзей и последних сообщений, связанных с ним;
- просмотр диалога двух username и журнала звонков (метаданные, без аудиозаписей);
- назначать роли может только владелец viva;
- кнопка сброса сообщества в админ-панели: сохраняет локальную резервную копию data.json, оставляет только viva и очищает друзей, сообщения, звонки, GIF, пользовательские страницы и валюты (создаёт Чекушня с нулевым балансом).

ВАЖНО:
1. Архив нужно загрузить в корень GitHub-репозитория с заменой файлов, затем Render выполнит деплой.
2. Очистка НЕ выполняется автоматически при деплое. Владелец вручную запускает её в Creator Studio → Community moderation → Reset community.
3. На Render без Persistent Disk локальный data.json и backup не гарантированно сохраняются после перезапуска/нового деплоя. Перед сбросом настройте Persistent Disk либо выгрузите резервную копию отдельно.
4. Эта сборка не является готовой заменой Discord на промышленном уровне. Для постоянного хранения нужен PostgreSQL/диск и объектное хранилище; для надёжных звонков в разных сетях нужен TURN-сервер. Проверены синтаксис server.js и app.js, но полный тест с двумя реальными пользователями не проводился.
5. Перед публичным запуском установите JWT_SECRET в Render Environment и смените пароль viva после первого входа. Если текущая база уже содержит viva, seedAdmin сохраняет текущий пароль.

Команды локального запуска:
npm install
npm start
