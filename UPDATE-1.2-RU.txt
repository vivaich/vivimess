ViviMess Update 1.2

Что исправлено:
- Удалён повторяющийся блок Creator Studio (и повторный customNav).
- Добавлены инструменты модерации: список аккаунтов, удаление аккаунтов владельцем viva, просмотр истории переписки двух пользователей.
- Добавлена история звонков (кто кому звонил, время и статус). Аудио звонков не записывается.
- Добавлено заметное уведомление в окне чата о возможности административной проверки переписки.
- Увеличен лимит Socket.IO для отправки видео/медиа; ограничение одного файла в чате — 8 МБ.
- Удалённые аккаунты больше не смогут продолжать использовать старый токен.

Обновление:
1. Распакуйте архив.
2. Откройте папку vm-work.
3. Загрузите ВСЁ её содержимое в корень GitHub-репозитория vivimess, заменив совпадающие файлы.
4. Сделайте Commit changes.
5. Render должен автоматически развернуть новый commit. Проверьте Deploys -> Live.

Важно:
- Перед обновлением сделайте резервную копию данных, если на Render уже есть реальные аккаунты/переписки. Render Free filesystem может быть временным; этот пакет не переносит существующий data.json.
- Удаление аккаунта необратимо удаляет его сообщения, заявки и дружбы из текущего JSON-хранилища.
- Модерация переписки доступна администраторам и обозначена пользователям. История звонков содержит только метаданные; записи/прослушивания аудио нет.
- Отправка видео ограничена 8 МБ на файл. Для больших видео нужен отдельный файловый storage.
