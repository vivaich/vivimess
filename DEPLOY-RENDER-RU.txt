ViviMess — подготовка к публикации на Render

ВАЖНО:
Эта конфигурация создаёт бесплатный веб-сервис Render для тестирования.
Бесплатный Render может засыпать после периода бездействия.
Его файловая система временная: текущая версия проекта хранит данные в data.json,
поэтому аккаунты/сообщения могут пропасть после перезапуска или пересоздания сервиса.
Не приглашайте реальных пользователей и не используйте важные пароли, пока мы
не подключим постоянную базу данных (например, Supabase) и не проверим безопасность.

ПУБЛИКАЦИЯ ЧЕРЕЗ БРАУЗЕР (без команд):
1. Создайте аккаунт на https://github.com/
2. Нажмите New repository, назовите его vivimess и создайте Public repository.
3. В репозитории нажмите Add file -> Upload files.
4. Распакуйте этот архив на компьютере и перетащите ВСЕ файлы и папки из него
   (не сам ZIP и не внешнюю папку) на страницу загрузки GitHub.
5. Нажмите Commit changes.
6. Откройте https://render.com/ и войдите через GitHub.
7. Нажмите New -> Blueprint (или New Web Service, если Blueprint недоступен).
8. Выберите репозиторий vivimess и подтвердите создание.
9. Дождитесь статуса Live. Render покажет публичный адрес.

ПЕРВЫЙ ВХОД:
В проекте предусмотрена начальная учётная запись:
username: viva
password: vivaich11

Сразу после первого входа поменяйте пароль, если интерфейс поддерживает смену.
Пока отдельного безопасного процесса смены пароля нет — перед реальным публичным
запуском нужно добавить его и подключить постоянную БД.

Звонки:
Браузерные звонки требуют HTTPS и разрешения на камеру/микрофон.
Для соединений через некоторые сети потребуется TURN-сервер. В этой версии
используется публичный STUN, поэтому звонки могут работать не у всех пользователей.
