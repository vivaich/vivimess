ViviMess 5.0 — обновлённая сборка

Что сделано в этой версии:
1. Друзья: карточки на странице друзей и в заявках ограничены по высоте; сетка не растягивает единственную карточку на весь высокий блок.
2. Paint: добавлена палитра цветов, выбор пользовательского цвета, толщина кисти, ластик, отмена, очистка, цвет фона и 11 локальных фоновых пресетов (тетрадь, сетка, чертёж, космос, градиенты и др.). Рисунок можно отправить в открытый личный чат.
3. Roblox: карточка компактная, зелёная рамка, обложка игры, название с emoji и автор, если Roblox API возвращает эти сведения. Данные запрашиваются через серверный same-origin proxy, чтобы избежать браузерного CORS.
4. Сообщение с Roblox-карточкой больше не растягивает зелёный пузырь чата на всю ширину.
5. Creator Studio: исправлена категоризация панелей на основе английских и русских заголовков, фильтры показывают нужные разделы.
6. Предпросмотр страниц: улучшено открытие и скрытие панели.

Установка:
- Сделайте резервную копию data.json и убедитесь, что Render Persistent Disk подключён к каталогу проекта, если он используется.
- Загрузите содержимое vm-work в корень GitHub репозитория, не загружая локальный data.json с чужими/тестовыми данными.
- Commit changes и дождитесь Render Live.
- После деплоя откройте сайт с Ctrl+F5.

Проверки:
- node --check server.js
- node --check public/app.js
- ZIP integrity test

Ограничения:
- Roblox thumbnail/creator зависит от доступности Roblox API и наличия данных у конкретной игры.
- Для стабильных WebRTC звонков между разными сетями может понадобиться TURN-сервер; его нужно настроить в call settings.
- Групповые звонки, совместный Paint и полный Roblox Studio editor не заявляются как готовые функции в этой сборке.
- Реальный деплой и звонки между двумя физическими устройствами в этом окружении не тестировались.
